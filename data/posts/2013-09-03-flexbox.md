<strong>Flexbox</strong> is a new way to arrange blocks on a page. This is a technology created specifically for laying out elements, unlike floats. With <strong>Flexbox</strong> you can easily align elements horizontally and vertically, change the direction and order of elements, stretch blocks to the full height of the parent, or nail them to the bottom edge.<!--more-->

<b>UPD from 02/02/2017:</b> I made a convenient cheat sheet on flexbox, with live demos and descriptions from the spec: <a href="https://yoksel.github.io/flex-cheatsheet/">Flexbox cheatsheet</a>.

<p>The examples use only the new syntax. At the time of writing, they are most correctly displayed in <strong>Chrome</strong>. In Firefox they work partially, in Safari they don’t work at all.</p>

The specification in English is here: <a href="http://www.w3.org/TR/css3-flexbox/" title="w3.org/TR/css3-flexbox">w3.org/TR/css3-flexbox</a>.

According to <a href="http://caniuse.com/#search=flexbox">caniuse.com</a>, <strong>Flexbox</strong> is not supported by IE 8 and 9 and Opera Mini, and other browsers do not support all properties and/or require prefixes.

This means that the technology cannot be widely used right now, but now is the time to get to know it better.

First you need to know that flex elements are arranged along axes. By default, elements are arranged horizontally - along the <strong>main axis</strong> - the main axis.

<img src="//img-fotki.yandex.ru/get/6717/5091629.97/0_7a3b2_58e721f4_orig" title="Axes" alt="Axes"/>

You should also keep in mind that when using <strong>Flexbox</strong> for internal blocks, <code>float</code>, <code>clear</code> and <code>vertical-align</code>, as well as properties that define columns in the text, do not work.

<section id="display-flex" data-name="display-flex"><h2>Display: flex</h2>

And now we add <code>display: flex;</code> to the parent element.
Inner divs are lined up (along the main axis) with columns of the same height, regardless of content.


<iframe class="live-snippet" style="height: 220px" src="../assets/demo/flexbox/demo_2.html?output"></iframe>

<code>display: flex;</code> makes all child elements flexible - <code>flex</code>, and not inline or block-based, as was originally the case.

If the parent block contains images or text without wrappers, they become anonymous flex items.

<iframe class="live-snippet" style="height: 270px" src="../assets/demo/flexbox/demo_3.html?output"></iframe>

The <code>display</code> property for <strong>Flexbox</strong> can take two values:

<code>flex</code> - behaves like a block element. When calculating the width of blocks, the layout takes priority (if the blocks are not wide enough, the content may overflow the boundaries).

<iframe class="live-snippet" style="height: 200px" src="../assets/demo/flexbox/demo_4.html?output"></iframe>

<code>inline-flex</code> - behaves like inline block. Content has priority (content spreads blocks to the required width so that the lines fit, if possible).

<iframe class="live-snippet" style="height: 200px" src="../assets/demo/flexbox/demo_5.html?output"></iframe>

</section><section id="flex-direction" data-name="flex-direction"><h2>Flex-direction</h2>

The direction of block layout is controlled by the <code>flex-direction</code> property.

Possible values:

<code>row</code> - row (default value);

<code>row-reverse</code> - a row with elements in reverse order;

<code>column</code> - column;

<code>column-reverse</code> - a column with elements in reverse order.

</section><section id="flex-wrap" data-name="flex-wrap"><h2>Flex-wrap</h2>
There can be many blocks in one line. Whether they wrap or not is determined by the <code>flex-wrap</code> property.

Possible values:

<code>nowrap</code> - blocks are not transferred (default value);

<code>wrap</code> - blocks are transferred;

<code>wrap-reverse</code> - blocks are wrapped and arranged in reverse order.

<iframe class="live-snippet" style="height: 630px" src="../assets/demo/flexbox/demo_8.html?output"></iframe>

To shorten the properties <code>flex-direction</code> and <code>flex-wrap</code> there is a property: <code>flex-flow</code>.

Possible values: you can set both properties or only one. For example:

<code>flex-flow: column;</code>

<code>flex-flow: wrap-reverse;</code>

<code>flex-flow: column-reverse wrap;</code>

</section><section id="justify-content" data-name="justify-content"><h2>Justify-content</h2>
There are several properties for aligning elements: <code>justify-content</code>, <code>align-items</code> and <code>align-self</code>.

<code>justify-content</code> and <code>align-items</code> are applied to the parent container, <code>align-self</code> - to the children.

<code>justify-content</code> is responsible for alignment along the main axis.

Possible values ​​for <code>justify-content</code>:

<code>flex-start</code> - elements are aligned from the beginning of the main axis (default value);

<code>flex-end</code> - elements are aligned from the end of the main axis;

<code>center</code> - elements are aligned to the center of the main axis;

<code>space-between</code> - elements are aligned along the main axis, distributing free space among themselves;

<code>space-around</code> - elements are aligned along the main axis, distributing free space around them.

</section><section id="align-items" data-name="align-items"><h2>Align-items</h2>
<code>align-items</code> is responsible for alignment along the perpendicular axis.

Possible values ​​for <code>align-items</code>:

<code>flex-start</code> - elements are aligned from the beginning of the perpendicular axis;

<code>flex-end</code> - elements are aligned from the end of the perpendicular axis;

<code>center</code> - elements are aligned in the center;

<code>baseline</code> - elements are aligned along the baseline;

<code>stretch</code> - elements are stretched, occupying all the space along the perpendicular axis (default value).

</section><section id="align-self" data-name="align-self"><h2>Align-self</h2>

<code>align-self</code> is also responsible for aligning along the perpendicular axis, but is set to individual flex elements.

Possible values ​​for <code>align-self</code>:

<code>auto</code> is the default value. Indicates that the element uses the <code>align-items</code> of its parent element;

<code>flex-start</code> - the element is aligned from the beginning of the perpendicular axis;

<code>flex-end</code> - the element is aligned from the end of the perpendicular axis;

<code>center</code> - the element is aligned in the center;

<code>baseline</code> - the element is aligned along the baseline;

<code>stretch</code> - the element is stretched, occupying the entire height space.

</section><section id="align-content" data-name="align-content"><h2>Align-content</h2>
To control the alignment inside a multi-line flex container, there is the <code>align-content</code> property.

Possible values:

<code>flex-start</code> - elements are aligned from the beginning of the main axis;

<code>flex-end</code> - elements are aligned from the end of the main axis;

<code>center</code> - elements are aligned to the center of the main axis;

<code>space-between</code> - elements are aligned along the main axis, distributing free space among themselves;

<code>space-around</code> - elements are aligned along the main axis, distributing free space around them;

<code>stretch</code> - elements are stretched to fill the entire height (default value).
