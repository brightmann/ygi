I became interested in Unicode, wanted to see what characters were in it, and somehow a page appeared on its own where you can see most of the Unicode characters: <a href="https://yoksel.github.io/unicode-table/">yoksel.github.io/unicode-table</a>.<!--more-->

<div><span style="font-size:25px">✪</span> The site has codes for using characters in Html and Css. <span style="font-size:25px">✪</span></div>

You can read about its use in CSS in the article <a href="/content/">The content property</a>.

There are a lot of symbols, and they are divided into blocks. By default, my selection is shown, but you can see others.

Some blocks don't have enough fonts to display because there are so many Unicode characters and probably no one font contains all of them. The Arial Unicode MS font is used to display symbols (it has very good Unicode support), but by clicking on a symbol you can see its support in other fonts. The appearance of a character in different fonts can be very different.

The display of a character may vary not only in fonts, but also in browsers. This should definitely be taken into account.

To check support for Unicode characters, there is a site <a href="http://unicode.johnholtripley.co.uk/">unicode.johnholtripley.co.uk/</a>.
