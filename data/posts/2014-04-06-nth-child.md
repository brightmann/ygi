<code>:nth-child</code> is one of my favorite selectors because you can use it to <s>do cool colorful things</s> collect list elements into groups of arbitrary length and do all sorts of cool things with them: from striped tables to entire multi-colored designs, all without having to define additional classes or change the markup in any way. <!--more-->

Here's a simple example of striped tables:

Stripes make it easier for your eyes to glide along a long row or column, this increases the readability of large tables, and this can be done with just a couple of lines of CSS:


```css
/* Горизонтальные полоски */
TR:nth-child(odd) {
  background: #EEE;
}

/* Вертикальные полоски */
TD:nth-child(odd) {
  background: #EEE;
}
```

Or here's what you can do with a regular list like this:

```html
<ul>
  <li></li>
  <li></li>
  <li></li>
  <li></li>
  <li></li>
</ul>
```

<h2 id="how-it-works">How does nth-child() work?</h2>

The size of the loop is specified in parentheses: for example, <code>(3n)</code> will select every third element.
You can also set a shift forward or backward: <code>(3n+1)</code> - will find every third one and take one step forward, and <code>(3n-2)</code> - two steps back from what was found.
If the loop size is not specified - <code>(n)</code> - all elements of the list will be selected.
If the loop size is not specified, but a specific number is specified - <code>(5)</code> - the list element with this index is selected.

<code>nth-child</code> in its loop counts all elements that are at the same nesting level relative to the parent element.

The selector works in all modern browsers with CSS3 support.

<h2 id="nth-of-type">nth-of-type()</h2>

All the examples above are based on a uniform list, but what if we need to select, for example, several paragraphs in an article that contains not only paragraphs, but also headings?

Let's say we want to color the odd paragraphs, so we'll write something like:

```css
P:nth-child(odd)
```

but the result will be somehow strange (on the left), and if you try to write the same thing, but without the tag (on the right), it immediately becomes clear why:
