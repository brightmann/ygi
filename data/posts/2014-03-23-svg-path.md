Unlike <code>polygon</code>, the shape does not close on itself, but this can be done using an additional parameter.<!--more-->

The points of the figure are specified in the <code>d</code> attribute. The value contains commands that control the direction and appearance of the lines.
The <code>x</code> and <code>y</code> coordinates can be separated by a comma or space, but a comma is more descriptive.

All commands are identified by one letter and can be written in upper or lower case.
Uppercase indicates the use of absolute coordinates, lowercase indicates relative coordinates.

The examples below demonstrate the difference between absolute and relative coordinates. The difference is in the second line: <code>M 20,20 L 100,150</code> vs <code>m 20,20 L 100,150</code>.

Lowercase commands ( <code>m</code> and <code>l</code>) indicate to count coordinates not from the upper left corner of the canvas, but from the current point (example on the right):

Teams:

<h2 id="m" data-name="M, moveto">M, m</h2>

<code>M</code> - <b>moveto</b>, denotes the beginning of a new line - the point from which we begin drawing.

<i>Parameters: <code>x,y</code>.</i>

There can be several <code>M</code> commands in a line, each of them will indicate the beginning of a new line:

<svg class="svg" width="200" height="170"><path stroke="orange" stroke-width="3" d="M 20 20 L 150 150 M 50 20 L 180 150 "/></svg>

```html
<svg width="200" height="170">
  <path stroke="orange" stroke-width="3"
    d="M 20,20 L150,150
       M 50,20 L180,150"/>
</svg>
```

<h2 id="z" data-name="Z, closepath">Z, z</h2>

<code>Z</code> - <b>closepath</b> - closes the figure, drawing a line from the current point to the starting point. This command is case insensitive; <code>Z</code> and <code>z</code> will work the same.

<i>Options: no.</i>

<code>Z</code> eliminates the need to specify the last point with the coordinates of the first to complete the shape. In addition, if you close the shape manually, you may end up with a sloppy joint:

<svg class="svg" width="200" height="180"><path stroke="orange" stroke-width="10" fill="gold" d="M 100 20 L 180 160 L 20 160 L 100 20"/></svg>

```html
<svg width="200" height="180">
  <path stroke="orange" stroke-width="10" fill="gold"
    d="M 100,20 L 180,160
       L 20,160 L 100,20"/>
</svg>
```

Instead of the last point we use <code>Z</code> and we get a neatly closed figure:

<svg class="svg" width="200" height="180"><path stroke="orange" stroke-width="10" fill="gold" d="M 100 20 L 180 160 L 20 160 z"/></svg>

```html
<svg width="200" height="180">
  <path stroke="orange" stroke-width="10" fill="gold"
    d="M 100,20 L 180,160
       L 20,160 z"/>
</svg>
```

<h2 id="l" data-name="L, lineto">L, l</h2>

<code>L</code> - <b>lineto</b> - drawing a line.

<i>Parameters: <code>x,y</code>.</i>

It should be noted that it is not necessary to write <code>L</code> before each period:

<code>L 80,20 L 20,100</code> = <code>L 80,20 20,100</code>

Lines will work the same, but <code>L</code> is more convenient if the code is supposed to be read.

<svg class="svg" width="200" height="180"><path stroke="green" stroke-width="3" fill="none" d="M 20,50  L 80,20 20,100 150,50 50,150 150,120"/></svg>

```html
<svg width="200" height="180">
  <path stroke="green" stroke-width="3" fill="none"
    d="M 20,50
       L 80,20 20,100 150,50 50,150 150,120
       "/>
</svg>
```

<h2 id="h" data-name="H, horizontal lineto">H, h</h2>

<code>H</code> - <b>horizontal lineto</b> - drawing a horizontal line.

<i>Parameters: <code>x</code>.</i>

<h2 id="v" data-name="V, vertical lineto">V, v</h2>

<code>V</code> - <b>vertical lineto</b> - drawing a vertical line.

<i>Parameters: <code>y</code>.</i>

Using these commands it is very convenient to draw rectangular shapes:

<svg class="svg" width="200" height="200"><path stroke="lightseagreen" stroke-width="5" fill="turquoise" d="M 20,20 h 160 v 160 h -80 v -80 h -80 z"/></svg>

```html
<svg width="200" height="200">
  <path stroke="lightseagreen" stroke-width="5" fill="turquoise"
    d="M 20,20
       h 160 v 160 h -80 v -80 h -80 z
       "/>
</svg>
```

In addition to commands for drawing straight lines, there are several commands for drawing curves. They are quite interesting, although somewhat difficult to understand.

<i>The dotted line in the examples (where possible) shows what happens without the curve command. For me, the auxiliary line made the principle of operation of these commands somewhat clearer.</i>
