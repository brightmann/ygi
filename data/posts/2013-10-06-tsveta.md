I like the ability to specify colors in code in several different ways, depending on the purpose of use. There are 7 such methods in total.

The specification is here: <a href="http://www.w3.org/TR/css3-color/">w3.org/TR/css3-color/</a>.

So, the ways:<!--more-->

<h2 id="named-colors" data-name="Named colors">1. Named Colors</h2>

<img src="//img-fotki.yandex.ru/get/5010/5091629.98/0_7b9db_df6975c2_XL.png">

There are quite a lot of them, all colors can be found here: <a href="http://www.w3.org/TR/css3-color/#svg-color">w3.org/TR/css3-color/#svg-color</a>

For myself, I sorted them by shades, my color table is here: <a href="https://yoksel.github.io/handy-colors/">Handy colors</a>.

<strong>Advantage:</strong> after some time of use, you always know the name of the desired color, or vice versa - what the color whose name you see in the code looks like on the page.
Very convenient for experimenting with CSS.

<strong>Disadvantage:</strong> there are only 147 of them, and it is not always possible to choose the right set of shades.

<h2 id="rgb" data-name="RGB">2. RGB</h2>

<strong>R</strong>ed, <strong>G</strong>reen, <strong>B</strong>lue.

Can be set in two ways:

<iframe class="live-snippet" style="height: 320px" src="../assets/demo/tsveta/demo_1.html?output"></iframe>

<strong>Advantage:</strong> Color values ​​can be taken from Photoshop.

<strong>Disadvantage:</strong> it is inconvenient to select values ​​by hand, and you cannot specify values ​​using floating point numbers. For example, if you want to set some color after 25%, in numbers it will be 63.75 - a line with such a value will not work.

<h2 id="hex" data-name="HEX">3. HEX</h2>

This is the same RGB, but written in hexadecimal number system. Each pair of characters means in the same sequence red, green and blue colors in the range from 00 to FF.
If both characters in pairs are the same, you can use a short notation. For example: #FFFFFF → #FFF.

<strong>Advantage:</strong> it is convenient to take values ​​from Photoshop.
<strong>Disadvantage:</strong> It is inconvenient to select values ​​by hand, although common combinations are easy to remember, for example <span style="background:#F00"> #F00 </span> or <span style="background:#DDD"> #DDD </span> or <span style="background:#F90"> #F90 </span>.

<h2 id="rgba" data-name="RGBA">4. RGBA</h2>

RGB with transparency parameter (alpha).

<iframe class="live-snippet" style="height: 300px" src="../assets/demo/tsveta/demo_2.html?output"></iframe>

<strong>Advantage:</strong> availability of transparency and the ability to manage it flexibly.

<strong>Disadvantages:</strong> the same as for rgb. Also not supported in IE8 and below.

<h2 id="hsl" data-name="HSL">5. HSL</h2>

<strong>H</strong>ue - color. Set in the range from 0 to 360, it means the angle of the color wheel (a rainbow represented as a circle).
<strong>S</strong>aturation - color saturation, set as a percentage.
<strong>L</strong>ightness - color brightness, set as a percentage.

<h2 id="hsla" data-name="HSLA">6. HSLA</h2>

Like HSL, but with transparency.

For example:

```css
background: hsla( 0, 90%, 65%, .7 );
```

<h2 id="keywords" data-name="Keywords">7. Keywords</h2>

<code>transparent</code> - to indicate complete transparency.

<code>currentColor</code> is the current text color (<code>color</code>) for the element.

For example, you can write:

```css
border: 5px solid currentColor;
```

And by assigning each element its own text color, get frames of different colors:

<iframe class="live-snippet" style="height: 450px" src="../assets/demo/tsveta/demo_7.html?output"></iframe>

You can even omit the keyword completely, and the text color will be inherited automatically:

```css
box-shadow: inset 0 0 2.5em;
```
