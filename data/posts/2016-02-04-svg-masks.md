SVG masks are a very rich topic. In SVG, there are two ways to clip one element to another: <b>clip-path</b> and <b>mask</b>. <b>Clip-path</b> uses only the contours of shapes for cropping, ignoring fills and strokes, with <b>masks</b> everything is much more interesting: they take into account fills, strokes, and the brightness of the content.<!--more--> Moreover, you can insert a raster image into the mask, and then its dark and light areas will be used to create the mask.

The code for the simplest mask looks like this:

```html
<mask id="mask">
  <!-- содержимое маски -->
</mask>
```

Let's add a couple of figures for example:

```html
<mask id="mask">
  <g stroke="gray" stroke-width="12" fill="white">
    <circle cx="33%" cy="30%" r="20%" />
    <circle cx="52%" cy="62%" r="32%" />
  </g>
</mask>
```

The mask code is set inside the SVG and can be used both inside this element and in other SVG elements on the same page. It is also possible to use SVG masks in CSS (eg <code>mask: url(#mymask)</code>), but this only works in Firefox at the moment.

The only required attribute of the <code>mask</code> element is <code>id</code> - this is the identifier that is needed to connect the mask to the element, but there are other attributes:

<h2 id="maskUnits">maskUnits</h2>

Determines which coordinate system will be used for the <code>x</code>, <code>y</code>, <code>width</code> and <code>height</code> attributes, that is, for external dimensions and coordinates.

Possible values:

<code>userSpaceOnUse</code> - the current coordinate system of the element to which the mask is applied is used. If no transformations were applied, it corresponds to the coordinate system of the entire document (for example, <code>width: 100%</code> will be equal to the width of the entire SVG element).

<code>objectBoundingBox</code> - attributes <code>x</code>, <code>y</code>,

<code>width</code> and <code>height</code> are specified in parts or percentages of the size of the element to which the mask is applied (<code>width: 100%</code> will be equal to the width of the element with the mask).

If <code>maskUnits</code> is not specified, the value of <code>objectBoundingBox</code> is used.

With <code>objectBoundingBox</code> 50% is calculated relative to the element, with <code>userSpaceOnUse</code> - relative to the entire document.

With <code>objectBoundingBox</code>, coordinates and sizes can be specified both in parts of the whole and in percentages, that is, <code>.5</code> is the same as <code>50%</code>.
With <code>userSpaceOnUse</code> only percentage values ​​or values ​​in absolute units, such as pixels, will work.

<h2 id="maskContentUnits">maskContentUnits</h2>

Determines which coordinate system will be used for the contents of the mask, that is, the internal dimensions and coordinates.

Possible values:

<code>userSpaceOnUse</code> - for the contents of the mask, the current coordinate system of the element to which the mask is applied is used (without transformations it corresponds to the coordinate system of the entire SVG element).

<code>objectBoundingBox</code> - the coordinate system relative to the element is used for the contents of the mask; all sizes and distances are calculated based on the dimensions of the element with the mask.

If the <code>maskContentUnits</code> attribute is not set, the <code>userSpaceOnUse</code> value is used.

Please note that with <code>objectBoundingBox</code> the shapes may become distorted (in this case, the circle turns into an ellipse).

Unlike <code>maskUnits</code>, with <code>objectBoundingBox</code> coordinates and sizes can only be specified in parts of the whole (possible values ​​are from 0 to 1), percentage values ​​will not work.

That is, it’s not that they won’t be at all - percentage values ​​will be calculated relative to the size of the entire SVG, and in this case <code>.5</code> is not at all equal to <code>50%</code>, because <code>.5</code> is half of the element with a mask, and <code>50%</code> is already half of the entire SVG image. And if you change the <code>maskContentUnits</code> values, you will have to rewrite the dimensions and coordinates of the mask contents each time.

<h2 id="x-and-y">X and Y</h2>

Determines where the top left corner of the displayed mask area will be. The contents of the mask do not move.

For <code>x</code> and <code>y</code> the default value is <code>10%</code>.

<h2 id="width-and-height">Width and height</h2>

Determines where the lower right corner of the displayed mask area will be. The external dimensions of the mask do not affect the dimensions of its contents.

For <code>width</code> and <code>height</code> the default value is <code>120%</code>.
