And now the steps:

<strong>1.</strong> Create the basis of the future cube:

```html
<div class="container">
  <div class="back side"></div>
  <div class="left side"></div>
  <div class="right side"></div>
  <div class="top side"></div>
  <div class="bottom side"></div>
  <div class="front side"></div>
</div>
```

One parent container and 6 faces.
The sequence is determined by the proximity of the wall to the viewer: the back wall is behind everyone else, the front wall is in front of everyone.

<strong>3.</strong> We begin to move the walls. All faces must be moved away from the center by half the length of the face and rotated by an angle corresponding to the position of the face in space. Let's start with the back wall:

<code>transform: translateZ(-5em);</code> - shift the wall in depth.

<p data-height="350" data-theme-id="4974" data-slug-hash="mwRxBj" data-default-tab="result" data-user="yoksel" data-embed-version="2" data-pen-title="3D Cube Tutorial, fig. 3" class="codepen">See the Pen <a href="https://codepen.io/yoksel/pen/mwRxBj/">3D Cube Tutorial, fig. 3</a> by yoksel (<a href="https://codepen.io/yoksel">@yoksel</a>) on <a href="https://codepen.io">CodePen</a>.</p>
<script async src="https://production-assets.codepen.io/assets/embed/ei.js"></script>

And nothing happens because the scene has no set perspective. Add:

```css
BODY {
  perspective: 1000px;
  perspective-origin: center -5em;
}
```

The first line is the depth of perspective.
The second property determines from which point we look at the object.
I set the view of the object a little from above (<code>-5em</code>).

To prevent the container from sticking together, you need to add 3D support to it:

```css
transform-style: preserve-3d;
```

The perspective is set for external objects (for the entire scene), and not for the container with transformations, because it should not depend on the movements of the transformed element in space.
If you set it for a container, it will be fixed and will move along with the entire object (example on the right).

To see how the walls move, it is convenient to give each of them its own background.
I also added <code>opacity: .7;</code> to the walls to make the cube translucent.

<strong>4.</strong> Now let's install the side walls. To see the resulting figure in volume, add animation to it:

```css
@keyframes rotate {
  100% {
    transform: rotateY(360deg);
  }
}

.container {
  ...
  animation: rotate 10s infinite linear;
}
```

To put the walls in place, first move them half the width of the cube along the X axis:


```css
transform: translateX(-5em);
```

And then rotate it 90 degrees around the vertical axis. Here is all the code for the left wall:

```css
.left {
  transform: translateX(-5em) rotateY(90deg);
}
```

The right one moves similarly, but in the opposite direction along the X axis.

<strong>5.</strong> Position the top and bottom. To do this, they need to be moved along the vertical axis by half the width of the cube:

```css
transform: translateY(-5em);
```

And rotate 90 degrees around the horizontal.

Code for top edge:

```css
.top {
  transform: translateY(-5em) rotateX(90deg);
}
```

The bottom one is done in the same way, but shifted to the other side along the Y axis.

<strong>6.</strong> The last step is to put the front wall in place. You can simply move it forward:

```css
.front {
  transform: translateZ(5em);
}
```
